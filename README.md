# 🦙 Chat with Docs — Local RAG using Gemma 3 (4B)A **private, local-first Retrieval Augmented Generation (RAG)** application that lets you chat with your PDF documents using **Google’s open-source Gemma 3 4B Instruct model**.No cloud calls. No external APIs. Your data stays on your machine.**Tech Stack:** Streamlit · LangChain · PyTorch · Hugging Face Transformers · FAISS---## ✨ Key Features* **Fully Local & Private**  All processing happens on your system. No document or query data is sent externally.* **LLM: Gemma 3 4B (Instruct)**  High-quality reasoning and instruction-following using a lightweight open-source model.* **End-to-End RAG Pipeline**  * **Embeddings:** `sentence-transformers/all-MiniLM-L6-v2` (fast & memory-efficient)  * **Vector Store:** FAISS (in-memory similarity search)  * **Chunking:** Recursive character splitting with contextual overlap* **User Interface**  * Streamlit-based chat UI  * Chat history  * Source-aware responses  * On-the-fly document ingestion---## 🛠️ Prerequisites### Software* **Python 3.10+**### Hardware* **RAM:** Minimum 16 GB  > Gemma 3 4B requires ~10 GB RAM just to load.* **GPU (Recommended):**  * NVIDIA GPU with CUDA **or**  * Apple Silicon (M1 / M2 / M3 via MPS)  > CPU-only execution is supported but significantly slower.### Hugging Face AccessGemma 3 is a gated model.1.
